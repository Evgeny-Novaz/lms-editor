# AI-редактор курсов LMS

Сайт: https://evgeny-novaz.github.io/lms-editor/

Обновления ветки `main` автоматически собираются и публикуются через GitHub Actions.

Клиентский прототип редактора Центрального университета на React 19, Vite, Tailwind CSS, Radix UI и Lucide, с компонентами в стиле shadcn/ui.

## Запуск

Требуются Node.js 22+ и pnpm 10.11.0.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

```sh
pnpm build
pnpm exec vite preview
```

Статическая сборка находится в `dist/`. Настройка `base: './'` поддерживает размещение в подпапке. API-ключи не нужны.

## Возможности

- Карточки курсов, поиск, режим списка и вспомогательный чат.
- Темы и уроки с плавными аккордеонами и перетаскиванием.
- Меню урока: открытие и удаление с восстановлением. Переименование и дублирование пока неактивны.
- Редактор текста с выбором стиля, форматированием, таблицами, изображениями, ссылками, предпросмотром и историей версий.
- Чат в одну строку с раскрытием при фокусе.

## Демонстрация создания урока из PDF

1. Откройте **Экономика → Макроэкономика** и создайте урок с любым названием.
2. Прикрепите **любую PDF**, введите любой текст и отправьте запрос.
3. Около 30 секунд редактор показывает скелетоны.
4. Появится заранее подготовленный материал «Введение в макроэкономику» с оформленными определениями, примерами, формулами и раскрываемой сноской.

Загруженный файл служит триггером: его содержимое не анализируется и не влияет на результат. Все AI-сценарии фиксированные, реальная модель не подключена.

В карточке улучшений можно удалить ненужные пункты и применить оставшиеся общей кнопкой. Предыдущая версия урока сохраняется. Правила оформления: [DEMO_GUIDELINES.md](DEMO_GUIDELINES.md).

## Данные

Исходные курсы и учебные материалы включены в исходники и `src/data/`. «Проектирование интерфейсов» показан опубликованным. В «Экономике» изначально есть пустая тема «Макроэкономика», урок создаётся вручную.

Изменения через интерфейс сохраняются в localStorage конкретного браузера и адреса; в GitHub они автоматически не попадают. Интеграции с LMS и серверного хранения нет. «Опубликован» — локальный статус прототипа.

Для сброса изменений выполните в консоли браузера на странице приложения:

```js
['lms-courses-v1', 'lms-docs-v1', 'lms-versions-v1', 'lms-last']
  .forEach(key => localStorage.removeItem(key));
location.reload();
```
