# Правила демонстрационных уроков

- Заголовки писать в обычном регистре: первая буква предложения заглавная, остальные строчные. Не использовать сплошные прописные, даже если они есть в PDF.
- Сохранять регистр аббревиатур (например, ВВП, КНР, США).
- Текст источника не сокращать и не перефразировать. Изменение регистра заголовков разрешено пользователем отдельно.
- Рекомендации по улучшению показывать отдельно и не применять автоматически.
- Оформление блоков из PDF и интерактивной сноски закреплено в src/macro-format.mjs и src/style.css и должно сохраняться при повторных демонстрациях.

- В уроках темы «Макроэкономика» курса «Экономика» любая приложенная PDF запускает подготовленный сценарий. Содержимое и имя файла не влияют на результат: через 30 секунд выводится неизменный текст исходного into-macro.pdf с настроенным оформлением.

- У каждого предложения по улучшению есть действие. Дополнения показываются на просмотр и добавляются только после «Применить»; план проверки не выдаётся за выполненную проверку источников.

- В карточке улучшений одна общая кнопка «Применить». Ненужные пункты удаляются крестиком. Применяются только оставшиеся, ещё не применённые пункты, с сохранением предыдущей версии. Проверка источников создаёт редакторский список задач, а не выдуманные результаты проверки.
